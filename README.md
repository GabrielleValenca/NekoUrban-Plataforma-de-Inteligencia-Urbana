# NekoUrban

O **NekoUrban** é uma plataforma web desenvolvida para facilitar o registro e acompanhamento de problemas urbanos, aproximando os cidadãos da administração pública.

Por meio da plataforma, o cidadão pode registrar problemas encontrados na cidade, informar sua localização, adicionar uma descrição, selecionar uma categoria e enviar uma imagem.

As informações registradas são organizadas para que possam ser consultadas e analisadas, permitindo identificar os principais problemas, regiões mais afetadas e situações que precisam de maior atenção.

##  Objetivo

O projeto tem como objetivo utilizar a tecnologia para melhorar a comunicação entre população e administração pública, transformando ocorrências individuais em informações que possam auxiliar na tomada de decisões e no planejamento urbano.

## Funcionalidades

* Cadastro e login de usuários;
* Registro de problemas urbanos;
* Adição de localização;
* Envio de imagens;
* Classificação por categoria;
* Consulta de ocorrências;
* Acompanhamento do status;
* Confirmação de problemas registrados;
* Dashboard administrativo;
* Gráficos e indicadores;
* Visualização das ocorrências em mapa.
